# 截哥 Cloud 管理台

管理台入口：`/admin/`。它是静态官网中的管理客户端，所有权限判定、资金变更和审计日志都在 Cloud API 服务器端完成，不依赖隐藏按钮作为安全边界。

## 角色

| 角色 | 权限 |
|---|---|
| Owner | 全部功能，含备份、审计和管理员权限 |
| Editor | 运营概览、文献与分类 |
| Finance | 运营概览、用户、订单、余额和充值记录 |
| Viewer | 仅运营概览 |

系统不允许停用或降级最后一个活跃 Owner。管理员密码使用随机 salt + scrypt 哈希，管理会话与普通用户会话使用不同密钥签名，会话令牌只保存在当前标签页的 `sessionStorage`。

## 文献

- 新增、编辑、草稿、发布、下架；
- 分类新增、编辑、排序、启用/停用；
- JSON 数组或 UTF-8 CSV 批量导入，每次最多 1000 条；
- DOI 已存在时更新原记录，否则新建；
- 只有 `published` 会出现在 `/v1/public/literature`。

CSV 字段：

```text
title,authors,year,doi,url,abstract,keywords,categoryId,status,source,notes
```

`authors` 用分号分隔，`keywords` 用逗号或分号分隔。

## 资金和订单

人工订单先创建为 `pending`，只有点击“确认收款”才会在同一数据库事务中同时：

1. 修改订单状态；
2. 增加用户余额和累计购买；
3. 写入积分账本；
4. 写入充值记录；
5. 写入管理员审计日志。

退款会扣回对应积分；若用户当前余额不足，系统拒绝自动退款，防止账本出现负数。同一订单的重试不会重复入账。

## 审计与备份

文献、分类、用户状态、余额、订单、备份与管理员变更均记录管理员、IP、User-Agent、对象、参数摘要和时间。

备份是 PostgreSQL 可重复读一致性快照，序列化为 JSON，再用 GZIP 压缩并计算 SHA-256。下载请求必须携带 Owner 会话。
