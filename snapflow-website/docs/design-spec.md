# SnapFlow Website Design Spec

- Brand gradient: `#00E5FF → #6C63FF → #FF6B9D`
- Accent yellow: `#FFD93D`
- Spacing: 8 px baseline.
- Type: Inter/system UI for Latin; PingFang SC/Source Han Sans/Noto Sans SC for Chinese; Cascadia Mono for code.
- Touch target: >=44 px.
- Breakpoints: 480 px, 880 px.
- Motion: transform/opacity only for primary reveal effects; all animation disabled under `prefers-reduced-motion`.
- Theme: light/dark stored in localStorage.
